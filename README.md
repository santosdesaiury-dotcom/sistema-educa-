# AVA-EDUCA+ - Sistema Educacional

Projeto desenvolvido para o curso Desenvolvedor-FrontEnd(Angular)- AVA-EDUCA+

👥 Integrante
Iury Santos de Sá - [ santosdesaiury@gmail.com ]

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica das páginas
- **CSS3** - Estilização, Flexbox, Grid e Responsividade (RF09)
- **JavaScript (ES6+ Modules)** - Lógica e interatividade
- **LocalStorage / SessionStorage** - Persistência de dados no navegador
- **ViaCEP API** - Preenchimento automático de endereço
- **Git / GitHub** - Versionamento de código

## 📋 Requisitos Funcionais Implementados

- **RF04 - Dashboard Dinâmico:** Contadores de alunos, cursos e progresso com cálculo real
- **RF05 - Cadastro de Aluno:** Validação (nome 4-80 chars, CPF 11 dígitos) + ViaCEP
- **RF06 - Listagem de Alunos:** Renderização dinâmica em tabela
- **RF07 - Listagem de Cursos:** Filtragem por professor logado (Ana Silva / Carlos Oliveira)
- **RF09 - Responsividade:** Layout adaptado para mobile (768px e 480px) com @media queries
- **RF11 - Programação Orientada a Objetos:** Classe `Aluno` em `js/Aluno.js` com encapsulamento
